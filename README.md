# Pata & Cia — Página de vendas PET

Landing page responsiva em português para uma loja de produtos pet, feita com HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — conteúdo e estrutura da página.
- `styles.css` — identidade visual, layout responsivo e componentes.
- `script.js` — filtros de produtos, sacola, menu mobile e formulário demonstrativo.

## Como visualizar

Abra `index.html` no navegador ou publique o repositório com GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)).

## Antes de vender de verdade

Os produtos, preços, imagens e depoimento são conteúdo demonstrativo. Atualize-os para os dados reais da loja. O carrinho funciona no navegador, mas o checkout ainda não processa pagamentos nem envia pedidos. Conecte um gateway de pagamento ou WhatsApp comercial e um serviço de e-mail para ativar essas funções.

As imagens são carregadas de URLs externas do Unsplash e as fontes do Google Fonts.
